One joke about office life, one line, under 200 characters — written for the
[Make the AI Judge Laugh](https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825)
competition on make.fun.

## The joke

> Our printer only jams on urgent documents — at this point I'm convinced it can read, and it enjoys the power.

## How it works

`main.py` prints the joke and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).

```sh
python3 -P -s main.py
```
